# Moo Security Tool V3.0 - Kali Edition

A lightweight, fast and colorful Port Scanner built for Kali Linux by Moo.

### 🔥 Features
- Fast TCP Port Scanning
- Colorful Output (Open = Green, Closed = Red)
- Detects Common Services
- Shows Scan Time
- 100% Python

### 🚀 Usage
```bash
git clone https://github.com/mohandm00990-cyber/moo-security-tool.git
cd moo-security-tool
python3 security_tool.py
